# Troubleshooting

Troubleshooting documentation will start from symptoms and include safe diagnostics before destructive recovery actions.

Coverage includes install/startup failures, Docker health, database/Redis connectivity, migrations, TLS/DNS, SMTP, login/MFA, Agent enrolment, remote sessions, patch jobs, Windows Update, App Portal, licensing and backup/restore.

Each guide must state which logs/commands are safe to collect and redact secrets/tokens from examples.
