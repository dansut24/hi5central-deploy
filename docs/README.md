# Hi5Central Documentation

This directory is the version-controlled source for the Hi5Central documentation portal.

Public documentation target: `https://help.hi5central.com`.

## Documentation map

- `getting-started/` — product overview, prerequisites and first-run onboarding.
- `self-hosting/` — Standard self-host installation, upgrades, backup/restore and migration.
- `msp/` — MSP licensing, multi-tenancy, white-labelling and customer administration.
- `platforms/` — ITSM, RMM, Platform Admin, Agent, Viewer and App Portal guides.
- `features/` — feature-specific configuration and enablement guides.
- `troubleshooting/` — diagnostics, common failures, logs and recovery procedures.
- `api/` — API authentication, conventions, examples and generated OpenAPI reference.
- `operations/` — Dev/Prod, releases, monitoring and disaster recovery.
- `security/` — software signing, trust model, secrets and hardening.

Documentation is part of the release definition. User-facing behaviour and API changes must update their corresponding documentation before production promotion.
