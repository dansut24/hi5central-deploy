# Hi5Central API

Hi5Central is API-first. The Hono Control Server is the authority for product behaviour, permissions, tenancy and edition entitlements.

The API documentation will contain:

- base URLs and API versioning;
- interactive OpenAPI reference;
- authentication (sessions and API tokens);
- pagination, filtering and search conventions;
- errors and idempotency;
- rate limits;
- tenant scoping;
- ITSM resources;
- RMM devices, jobs, patching and remote-session resources;
- App Portal resources;
- MSP/Platform Admin resources;
- licensing endpoints;
- webhooks/events when introduced;
- worked integration examples.

The canonical machine-readable specification will be published as `/api/v1/openapi.json` and used to generate the reference pages so implementation and documentation cannot silently diverge.
