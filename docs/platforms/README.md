# Platform guides

Product documentation is split by surface so administrators and technicians can work from task-focused guides rather than source-code concepts.

Planned guides:

- ITSM: incidents, requests, changes, knowledge, live chat, projects, workflows, notifications and configuration.
- RMM: devices, inventory, remote access, patching, OS updates, automation, policies, network discovery and recovery keys.
- Platform Admin: managed-service control plane, tenants, billing, releases, qualification and MSP licensing.
- Windows Agent: installation, enrolment, service lifecycle, logs, upgrades and diagnostics.
- Viewer / Connect: attended and unattended remote access, consent and troubleshooting.
- App Portal / Self Service: publishing applications, assignments, installation and updates.
