# Self-hosting

Hi5Central Self-Hosted Standard is the free, proprietary, single-organisation edition. It uses the same signed/containerised application releases as Hi5Central-managed deployments and does not expose source code.

This section will cover:

- host prerequisites and sizing;
- DNS, TLS and firewall requirements;
- one-run installation;
- Standard versus MSP editions;
- first organisation setup;
- SMTP and Microsoft integration;
- Agent/Viewer/App Portal deployment;
- upgrades and release channels;
- backup, restore and disaster recovery;
- moving a deployment to another server;
- offline and restricted-network operation;
- uninstall/removal.
