### Release rules

- Maintain at least one verified local rollback copy of the active RMM web image and API image; never prune these images during VPS cleanup.
- Build/test a new Agent installer separately; avoid changing the shared tenant installer template until accepted.
- No Viewer/Agent/API changes as part of device inventory work.
- Check for active sessions before replacing the RMM web or API containers. Do not interrupt an existing session just to update inventory.
- Rollbacks should use Compose restoration and should not delete persistent volumes, Agent/tenant mappings or credential state.
- Validate logon, lock screen, UAC, user switch, iPhone Safari keyboard/touch, and reconnect before moving the production baseline.

Use `scripts/verify-rmm-20261029-baseline.sh` on the VPS to detect unexpected image or Viewer drift without restarting services.
